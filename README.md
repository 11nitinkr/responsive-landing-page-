# NOVA ONE — Responsive Product Landing Page

A modern and responsive product landing page built as part of my web development internship tasks.

The main goal of this project was to practice the fundamentals of front-end development by creating a complete landing page using only **HTML, CSS, and Vanilla JavaScript**, without using frameworks such as React, Bootstrap, or Tailwind CSS.

## About the Project

NOVA ONE is a fictional smart workspace hub designed for people who want a cleaner and more productive desk setup.

I designed the website with a modern dark interface, smooth interactions, responsive layouts, and a product-focused visual style.

The project focuses on creating a professional-looking landing page while keeping the code simple and easy to understand.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

No CSS or JavaScript frameworks were used in this project.

## Main Features

- Responsive layout for desktop, tablet, and mobile devices
- Semantic HTML5 structure
- Modern navigation bar
- Mobile hamburger menu
- Smooth scrolling between sections
- Active navigation link highlighting
- Scroll reveal animations
- Product hero section
- Features section
- Product design section
- Specifications section
- Customer reviews section
- Call-to-action / pre-order section
- Responsive footer
- CSS-based product illustrations and visual elements
